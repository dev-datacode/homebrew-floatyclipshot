# Homebrew Tap for FloatyClipshot

This is the official Homebrew tap for [FloatyClipshot](https://github.com/dev-datacode/floatyclipshot).

## Installation

```bash
brew tap dev-datacode/floatyclipshot
brew install --cask floatyclipshot
```

## Update

```bash
brew upgrade --cask floatyclipshot
```

## Uninstall

```bash
brew uninstall --cask floatyclipshot
brew untap dev-datacode/floatyclipshot
```
