# Homebrew Tap for FloatyClipshot

This is the official Homebrew tap for [FloatyClipshot](https://github.com/hooshyar/floatyclipshot).

## Installation

```bash
brew tap hooshyar/floatyclipshot
brew install --cask floatyclipshot
```

## About FloatyClipshot

A macOS screenshot utility designed for developers who need instant, friction-free screenshots during mobile/web development.

### Features

- One-click screenshot capture via a floating, always-on-top, draggable button
- Window-targeted captures
- Multi-desktop support
- Smart terminal detection
- Customizable global keyboard shortcuts
- Instant clipboard integration

For more information, visit the [main repository](https://github.com/hooshyar/floatyclipshot).
